# 가상 거래 예시

[demo-bank.csv](demo-bank.csv)는 제품 확인을 위해 새로 작성한 가상 거래 4건입니다. 실제 회사·통장·직원·거래와 관계가 없습니다. 은행 계좌번호나 외부 서비스 인증정보가 들어 있지 않습니다.

1. [설치 안내](../README.md)에 따라 자신의 독립 DB와 최초 관리자를 준비합니다.
2. 설정에서 `가상 사업자`와 그 사업자의 `가상 운영통장`을 등록합니다. 실제 은행 정보를 입력할 필요는 없습니다.
3. 거래 업로드에서 이 CSV와 가상 운영통장을 선택합니다. 날짜·적요·입금·출금·잔액·과목 열이 미리보기와 일치하는지 확인합니다.
4. 신규 거래를 적용한 뒤 조회기간을 `2026-11-01 ~ 2026-11-30`으로 선택합니다.

| 확인할 항목 | 가상 금액 |
| --- | ---: |
| 매출 입금 | 1,000,000원 |
| 급여 출금 | 300,000원 |
| 지급수수료 출금 | 60,000원 |
| 총 출금 | 360,000원 |
| 마지막 기록 잔액 | 640,000원 |

거래 내역·월간 보고와 달력에서 같은 원본 거래를 확인할 수 있습니다. 같은 CSV를 다시 가져올 때 기존 거래를 새 거래로 중복 저장하지 않는지도 확인합니다. 가용자금 계획의 예정 지출은 별도로 등록하며, 이미 출금된 360,000원을 현재 잔액에서 다시 차감하지 않습니다. 기본 설치에서는 업종 참고치와 과거완료 날짜를 임의로 적용하지 않습니다.

연동 버튼의 실제 외부 조회에는 설치자 자신의 계정·권한·설정이 필요합니다. 이 예시는 외부 조회 결과나 은행의 실시간 잔액을 제공하지 않습니다.
